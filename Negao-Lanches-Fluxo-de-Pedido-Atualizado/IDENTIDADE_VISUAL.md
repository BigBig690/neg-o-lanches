# Identidade visual — Negão Lanches

- **Direção:** lanchonete acolhedora com personalidade forte, aparência moderna e foco no cardápio.
- **Cores:** vermelho como cor de ação, carvão para cabeçalho e hero, creme como base, dourado para destacar o produto especial.
- **Tipografia:** Barlow Condensed para títulos e DM Sans para leitura e interface, com fontes de sistema como fallback.
- **Componentes:** botões arredondados, cartões de produto, filtros por categoria, carrinho claro e etapas de compra visíveis.
- **Responsividade:** layout adaptado para desktop, tablet e celular; navegação móvel, botões amplos e formulários de uma coluna em telas pequenas.
- **Fotografia:** imagens são ilustrativas e podem não representar exatamente a apresentação do item.
